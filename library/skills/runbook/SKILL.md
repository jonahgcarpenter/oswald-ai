# Runbook

Capture a procedure the operator repeats so the team can run it the same way.

## Procedure

1. Run the procedure once, noting every command and decision point.
2. Record it with `templates/plan.md` as the shape.
3. Save helper commands in `scripts/` instead of inline prose.
